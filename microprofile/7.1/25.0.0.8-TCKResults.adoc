= MicroProfile 7.1 TCK Results Summary

As required by the https://www.eclipse.org/legal/tck.php[Eclipse Foundation Technology Compatibility Kit License], following is a summary of the MicroProfile TCK results for MicroProfile 7.1.

== Open Liberty 25.0.0.7-beta-cl250620250508-1902 MicroProfile 7.1 Certification Summary

MicroProfile 7.1 consists of 7 MicroProfile Specifications and it depends on the Jakarta EE Core Profile 10.0 specfication.

* MicroProfile Config 3.1

* MicroProfile Fault Tolerance 4.1

* MicroProfile Health 4.0

* MicroProfile JWT Authentication 2.1

* MicroProfile OpenAPI 4.1

* MicroProfile Rest Client 4.0

* MicroProfile Telemetry 2.1

* Jakarta EE Core Profile 10.0

=== Product Name, Version and download URL (if applicable):
